# DrawUp V15.5 — Arch Coach connection fix

- Arch Coach now uses the same server-side `OPENAI_API_KEY` connection as DrawUp Search.
- Added `/api/arch-coach` Next.js server route.
- Recent conversation history is sent with every Coach request so follow-up context is preserved.
- Jurisdiction/code/zoning/ADA/permit/firm/project questions automatically enable live web research.
- Direct source links are rendered below researched Coach answers.
- The existing public Coach and the Coach embedded inside Portal use the same fixed route.
- Failed requests continue to display that the DrawUp allowance was not charged.
- No OpenAI key is exposed to the browser.

Netlify must contain `OPENAI_API_KEY`. If Netlify secret scanning flags generated Next cache files, keep `SECRETS_SCAN_OMIT_PATHS=.netlify/.next/cache/**`.
