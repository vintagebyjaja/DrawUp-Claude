# DrawUp V23 — Project-first release requirements

## Non-negotiable separation
- DrawUp 2D: existing 35 public categorized technical detail references. Preserve identifiers, categories, filtering and SVG/PNG/PDF exports.
- DrawUp 3D: public educational visualizations, proportionate but not necessarily dimensionally accurate. The construction assembly, material order and installation logic should be faithful to the source 2D detail. Hologram, exploded, section, layers and realistic modes are desired for all 35; do not represent placeholder graphics as finished source-matched views.
- My 3D: user's personal models and saved educational content.
- Firm: authorized current and previous firm libraries; each firm controls access, including revocation.

## Project-first three-stage workflow
1. Find the Flaws: inspect uploaded sheets, project phase, existing details, notes, schedules and discipline relationships. Save review progress by sheet.
2. Understand the Fix: explain project-specific gaps and proposed corrections; educational 3D examples are optional and never assumed applicable.
3. DrawUp Ready: propose and (when a reliable drawing engine exists) produce revised sheets, new sections/elevations/details/callouts based on THIS PROJECT'S geometry and documented assemblies, with user approval and revision history. Respect existing titleblock, firm standards and chosen print size. Never paste generic library details into a project without confirmed applicability and approval.

## Firm playbook
Extract candidate standards from uploaded PDF; firm admin approves them. Apply firm-specific approved categories, DrawUp General only as fallback. Preserve original playbook. General starter pack in PDF and editable PowerPoint.

## Check
Separate code, accessibility and life-safety review from project development. Process sheets independently, persist completed results and return partial results when a sheet fails or times out.

## Current implementation boundaries
The existing source includes UI, notes and references but does not implement production-grade AI redrafting, complete 35 source-matched 3D image sets, full firm permission history or verified permit-ready outputs. Do not claim these features are complete.
