# DrawUp V15 — Portal becomes the product

- Replaces empty Portal placeholders for Arch Coach, Check, Details, Discover and Connect with the existing functional public DrawUp workspaces, rendered inside the signed-in Portal shell.
- Projects now opens with Start New, Work with Arch Coach, and Let's Play, followed by project data when available.
- Search remains a permanent Portal tab with “What are you drawing up?” and invokes the same DrawUp search engine as the public experience without signing the user out.
- Public knowledge remains available while signed in; Portal adds account/project context rather than removing functionality.
- Removes the “lives inside your Portal” placeholder experience from these primary product tabs.
