# DrawUp V13.2 portal/auth hotfix

1. Deploy this ZIP to the SAME GitHub repository / Netlify site used by DrawUp.
2. Do NOT add the Supabase folder to GitHub.
3. V13.1 migration 0017 must already be applied (onboarding columns + unlimited_access).
4. Sign out, hard refresh, then sign in with the personal account.
5. If onboarding_completed_at is null: white profile setup opens immediately.
6. Upload a profile picture, choose profile fields, or skip optional steps.
7. Enter DrawUp -> portal.
8. Sign out and sign back in -> tunnel -> portal.
9. Paid plan buttons require authentication before selection.

V13.2 also fixes laptop hero containment: copy stays inside viewport; command-center artwork may crop/bleed to the right.

Profile photos are resized client-side to a 384px square JPEG and stored in the existing profiles.avatar_url field for this test build, so no additional Supabase storage bucket is required to test photo upload.
