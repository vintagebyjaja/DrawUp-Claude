# DrawUp V13.10 Combined

This package is the cumulative build combining V13.8 portal access/session hotfixes with V13.9 functional portal/profile/firm/details catalog work.

Included from V13.8:
- authenticated session enters Portal instead of being blocked by onboarding
- incomplete/failed enrichment cannot block Portal access
- signed-in Portal shell and routing behavior

Included from V13.9:
- functional Profile tabs
- functional Firm tabs / Firm Library UI
- Details catalog and upload UI
- contributor eligibility / destination controls for Firm Library and DrawUp Details

The separate V13.9 Supabase SQL is still required for persistent catalog/file-storage records and is intentionally not placed in the GitHub deploy package.
