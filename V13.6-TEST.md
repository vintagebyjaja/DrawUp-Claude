# DrawUp V13.6 Test

## Persistent onboarding
- Complete onboarding once, sign out, then sign back in.
- Returning sign-in should go to the portal tunnel/portal, not onboarding.
- Profile identity fields are saved to Supabase as the user moves through setup.
- If setup is interrupted before completion, saved identity fields should prefill on return.
- Profile > Edit Profile intentionally reopens the setup editor.

## Unique usernames
- Username is normalized without a leading @ and stored lowercase.
- Availability is checked against public.profiles while typing and again before completion.
- A username used by another profile blocks Continue/completion.
- The existing case-insensitive unique database index remains the final database-level protection.
