# DrawUp V16.1 Portal Router Fix

Root cause found in V16: the original Portal dispatcher still contained hard-coded `renderSimple(...)` placeholder routes for Projects, Arch Coach, Check, Details, Discover and Connect. Later feature code existed in the same JS file, but the active route chain could still resolve to the old placeholder renderer.

V16.1 adds one authoritative router at the end of the production Portal script. Projects now calls the real project workspace (including DrawUp Athletic Storage Bldg Example), Arch Coach calls the native thread/composer interface, Details calls the catalog, Search calls DrawUp Search, and Profile uses the persistence/editable profile renderer. The old placeholder renderer is no longer an active destination.

The script URL is cache-busted to v=16.1.
