# DrawUp V14.1 — Search Result Presentation

- Search results no longer lead with DrawUp verification status.
- When the search backend returns project data, DrawUp renders it as a normal project profile.
- Supports project hero imagery plus architect, engineer, contractor, owner/developer, dates, area, cost and capacity.
- Source results can render as rich cards with publisher, headline, preview image, summary/snippet and View Source link.
- Supports array-style legacy sources and richer object-style sources from `drawup-search`.
- Missing project fields are simply omitted.
- If the backend returns no usable sources, DrawUp provides ArchDaily, news, project and image research routes instead of an apology/verification screen.
- Full automatic article discovery still depends on the deployed `drawup-search` Edge Function returning those sources/data.
