MONROE SCHOOL — ORIGINAL + OPTIONS 1–3

Four editable neighborhood models. Original means original road layout with updated building materials and the authorized school height correction.
Option 1: 142 spaces; Option 2: 140 spaces; Option 3: 152 spaces.
Buildings remain individually selectable; material faces use brick, concrete, glazing, metal and roof finishes. Existing white finishes remain light. Main school long wing is three stories, square wing two. No car props are included.
All public road meshes and all building footprints retained. The original 50th hill path/stairs remain, with a new stair/landing connection to the campus road. Private site terrain and pavement are graded; birdseye previews hide the elevation changes.

FORMATS
BLEND: open in Blender; facade images packed. FBX: embedded textures. COLLADA/DAE: extract the entire archive with Shared_Textures beside model folders, then import into SketchUp Desktop. Meter units / Z up. No native SKP is supplied; SketchUp import has not been tested in SketchUp itself. Optional Ruby helper converts an imported DAE to SKP using your installed SketchUp.

CHECKS AND LIMITS
Final sampled passenger vehicle parking entry/reverse-exit paths pass for all modeled spaces, with neighboring cars represented as occupied obstacles. Vehicle 4.8 x 1.85 m, wheelbase 2.8 m, 35-degree steering limit, 0.15 m body clearance. Campus connection to Finch checked for pavement connectivity. This is a geometric concept assessment, not a full route simulation for every possible driver or large/service/emergency vehicle.
Parking dimensions: 9 x 18 ft stalls; 22 ft aisles beside perpendicular spaces; 13 ft angled aisles. Mixed module remains 134 x 60 ft, 28 spaces. Approved bank shifts and corner paving included.
Based on supplied imagery and native model, not a measured survey. Grading, accessibility, drainage, retaining structures and construction compliance need engineering review. These are presentation/concept models.

OPENING THE FILES
Each file contains the full neighborhood, so importing the large DAE scenes can take several minutes. Keep Shared_Textures in the extracted archive root. Blender opens to the campus overhead view; use the camera view for the presentation composition. Parking, striping, curbs, the path connection and individual buildings remain selectable meshes.
