# DrawUp V15.2 — Search Research Engine

V15.2 removes Google/search-engine redirect fallbacks from DrawUp project search.

## What changed
- New server route: `/api/project-research`
- Uses OpenAI Responses API web search server-side to research project/building queries.
- Prioritizes direct AEC/project sources, including architect/engineer/owner pages, ArchDaily, construction/architecture publications, government documents and news coverage.
- Returns structured DrawUp project data and direct source URLs.
- Public and Portal search continue to share the same DrawUp renderer/search flow.
- Existing Supabase `drawup-search` remains a secondary provider/cache.
- Missing fields are omitted; users are not sent to Google to finish the research.

## Netlify environment variable required
Add `OPENAI_API_KEY` to the production Netlify environment. Keep it server-side only. Do not prefix it with `NEXT_PUBLIC_`.

Optional: `DRAWUP_SEARCH_MODEL=gpt-5.6-luna`.
