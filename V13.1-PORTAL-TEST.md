# DrawUp V13.1 Portal Test

Run Supabase migration 0017 first, then deploy this GitHub package to the same DrawUp Netlify site.

Expected behavior:
- Existing signed-in users whose onboarding_completed_at is null see the white profile setup on their next portal entry.
- Completing setup writes the profile and opens the signed-in DrawUp portal.
- Later sign-ins play the DrawUp portal tunnel, then open the portal.
- Profile is available from the signed-in header and mobile bottom navigation.
- Paid pricing buttons require authentication before continuing.
- The personal unlimited_access flag is displayed as Unlimited Arch Coach when present.

To retest first-time onboarding for one test user, set that user's profiles.onboarding_completed_at back to null in Supabase.
