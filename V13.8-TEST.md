# DrawUp V13.8 — Portal Access Hotfix

- Successful Supabase authentication always grants Portal access.
- Incomplete or failed profile enrichment can no longer trap a signed-in user in onboarding.
- Existing sessions reopen the Portal directly on reload/return.
- Profile loading has a short non-blocking timeout.
- Failed final onboarding save enters Profile inside Portal so details can be retried there.
- Portal assets renamed to v138 to prevent stale browser/CDN cache from serving the prior gate logic.
